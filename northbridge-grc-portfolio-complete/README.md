# Northbridge Cloudworks GRC Portfolio

Northbridge Cloudworks, Inc. is a fictional B2B SaaS company used to demonstrate practical governance, risk, and compliance work. The portfolio is built as one connected security program rather than disconnected school exercises.

## Company Scenario

Northbridge Cloudworks is a remote-first SaaS provider with approximately 120 employees. The company hosts its product in AWS, uses Microsoft 365, Okta, GitHub, Slack, Salesforce, Stripe, and several other SaaS vendors, and processes confidential customer business data. Leadership wants to mature the security program, align with NIST CSF 2.0, prepare for future SOC 2 readiness work, and make cyber risk visible to executive decision-makers.

## Verified 2026 Standards Baseline

This portfolio uses the following baseline as of August 13, 2026:

| Area | Standard / Framework | Portfolio Use |
|---|---|---|
| Cybersecurity framework | NIST CSF 2.0 | Program structure, current profile, target profile, gap assessment |
| Risk assessment | NIST SP 800-30 Rev. 1 | Risk scenario, likelihood, impact, and response methodology |
| Cyber risk to ERM | NIST IR 8286 Rev. 1 series | Risk register design, enterprise roll-up, governance reporting |
| CSF/ERM/workforce | NIST SP 1308 | Connecting risk decisions to business and workforce priorities |
| Security/privacy controls | NIST SP 800-53 Rev. 5 Release 5.2.0 | Control references and future control-library work |
| Control assessment | NIST SP 800-53A Rev. 5 | Evidence and testing logic |
| Supply chain risk | NIST SP 800-161 Rev. 1 Update 1 | Vendor and supply-chain risk where relevant |
| Prioritized safeguards | CIS Controls v8.1 | Practical safeguard mapping |
| ISMS requirements | ISO/IEC 27001:2022 + Amd 1:2024 | Governance and ISMS alignment |
| Security controls | ISO/IEC 27002:2022 | Control guidance and control language |
| SOC 2 | AICPA TSC with revised points of focus 2022 | SOC 2 readiness and audit-facing control language |
| Incident response | NIST SP 800-61 Rev. 3 | IR-related gap and risk treatment references |
| CUI / federal context | NIST SP 800-171 Rev. 3 | Used only when CUI or defense scenarios are in scope |
| Cloud controls | ISO/IEC 27017:2026 | Cloud-specific control references where relevant |
| Payment card scope | PCI DSS v4.0.1 | Used only when cardholder data environment assumptions are in scope |
