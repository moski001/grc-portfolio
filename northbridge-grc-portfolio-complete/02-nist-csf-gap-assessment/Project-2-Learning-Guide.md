# Project 2 Learning Guide

## What You Need To Understand

This project is about turning NIST CSF 2.0 into a practical current-state, target-state, and remediation roadmap exercise. The point is not to memorize every CSF outcome. The point is to show that you can interpret framework language, compare it against real organizational practices, and explain what should improve next.

## The Secret Sauce

Many candidates say:

> I am familiar with NIST CSF.

A stronger answer is:

> I built a NIST CSF 2.0 current-versus-target profile assessment, documented evidence, identified gaps, assigned owners, and converted those gaps into a phased remediation roadmap.

That answer stands out because it shows you understand how the framework is used in real GRC work.

## Core Concepts

### NIST CSF 2.0 Is Not A Certification

NIST CSF is a voluntary framework for organizing and communicating cybersecurity risk outcomes. Do not say a company is "NIST CSF certified" based on this project.

Strong answer:

> I used NIST CSF 2.0 as an assessment and communication framework, not as a certification checklist.

### Current Profile

The current profile describes what Northbridge does today.

Example:

> MFA exists, but privileged-user exceptions and evidence are not fully governed.

### Target Profile

The target profile describes what Northbridge should reasonably achieve based on its business, risk, size, customer expectations, and future SOC 2 readiness goals.

Example:

> Privileged MFA is enforced, exceptions are approved, and quarterly access reviews are evidenced.

### Gap

The gap is the difference between the current and target state.

Example:

> Current state has MFA enabled, but target state requires privileged MFA evidence and exception governance.

### Roadmap

The roadmap turns the gap into action. A good roadmap includes owner, priority, timing, and expected evidence.

## Where You Should Learn Deeply

### 1. GOVERN Is A Major CSF 2.0 Upgrade

NIST CSF 2.0 added GOVERN as a core function. This matters for GRC because governance is where accountability, policy, risk appetite, vendor oversight, and executive decision-making live.

Strong answer:

> GOVERN is especially important in GRC because it turns cybersecurity from a technical activity into an accountable management process.

### 2. A Gap Is Not Automatically A Finding

A gap means current state is below target state. A finding is usually a documented issue that requires remediation and tracking.

Strong answer:

> I would not treat every gap as equal. I would prioritize based on risk, business impact, customer commitments, audit readiness, and dependency on other controls.

### 3. Evidence Makes The Assessment Defensible

Weak answer:

> We marked this partially implemented.

Stronger answer:

> We marked it partially implemented because evidence showed the process exists, but ownership, review cadence, or operating evidence was incomplete.

## How To Explain The Workbook

Use this structure:

> The dashboard summarizes assessed outcomes, implementation status, high-priority gaps, and function-level themes. The assessment sheet documents CSF ID, function, current evidence, target state, gap, business risk, recommendation, owner, priority, and roadmap phase. The roadmap turns the assessment into 0-30, 31-90, 3-6 month, and 6-12 month actions.

## Smart Interview Phrases

- "I avoided creating a fake NIST score and focused on current state, target state, risk, and remediation."
- "I used the CSF functions to organize the conversation, but the roadmap is where the assessment becomes useful."
- "A framework assessment should result in decisions, owners, evidence, and follow-through."
- "GOVERN is where GRC analysts can add real value because it connects security work to management accountability."

## Practice Exercise

Pick one CSF outcome and answer:

1. What function does it belong to?
2. What is Northbridge doing today?
3. What evidence supports the current state?
4. What should the target state be?
5. What is the gap?
6. What risk does the gap create?
7. Who should own remediation?
8. What evidence would prove the gap is closed?
