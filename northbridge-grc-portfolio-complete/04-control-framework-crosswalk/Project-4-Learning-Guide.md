# Project 4 Learning Guide

## What You Need To Understand

This project is about translating frameworks into real control work. A framework tells you what outcome should exist. A control defines what the company actually does. Evidence proves the control exists or operates. Testing determines whether the evidence is good enough.

## The Secret Sauce

Many candidates say:

> I know NIST, CIS, ISO, and SOC 2.

A stronger answer is:

> I built a unified control library that maps one internal control to multiple frameworks, then tested whether selected controls were designed and operating effectively.

That answer sounds more competent because it shows you understand the work behind compliance.

## Core Concepts

### Control Objective

The control objective is the reason the control exists.

Example:

> Prevent unauthorized access to Northbridge systems and customer data.

### Control Activity

The control activity is what the company actually does.

Example:

> MFA is enforced for all workforce users, and privileged users are reviewed quarterly.

### Evidence

Evidence proves whether the control happened.

Example:

- Identity-provider MFA policy export
- User enrollment report
- Privileged user list
- Exception approval
- Access-review signoff

### Design Effectiveness

Design effectiveness asks:

> If this control operates as written, would it address the risk?

### Operating Effectiveness

Operating effectiveness asks:

> Did the control actually operate during the period?

This distinction is a major interview differentiator.

## Where You Should Learn Deeply

### 1. MFA Is Not Just "Turned On"

A strong answer:

> I would not conclude MFA is effective just because the company says it uses MFA. I would inspect policy configuration, user coverage, privileged-user enrollment, exception handling, and sample accounts.

### 2. Evidence Quality Matters

Weak evidence:

> The manager says access was reviewed.

Stronger evidence:

> A dated access review export with reviewer approval, user list, exceptions, and remediation notes.

### 3. Crosswalks Reduce Duplicate Work

One MFA control may support:

- NIST CSF Protect
- NIST 800-53 IA-2 / AC-2
- CIS Controls identity safeguards
- ISO access-control guidance
- SOC 2 common criteria

This is one of the most intelligent things you can explain in an interview.

## Practice Exercise

Pick one control and answer:

1. What risk does this control reduce?
2. What is the control objective?
3. What frameworks does it map to?
4. What evidence would you request?
5. How would you test design effectiveness?
6. How would you test operating effectiveness?
7. What would count as an exception?
8. How would you write the remediation?
